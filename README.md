# Cepidia — Product Development & Roadmap

Welcome to the public planning space for **Cepidia**, our school information system.

This repository provides a shared view of feature ideas, product improvements, accepted issues and development progress. It is intended for school leadership, staff, collaborators and the product team.

## How to contribute

1. Share early ideas and feedback in the Cepidia Slack **R&D** channel, and report problems in **Issues**.
2. When an idea or bug is accepted for tracking, create or reuse a [GitHub Issue](https://github.com/emre-ayhan/cepidia-planning/issues). Avoid duplicates.
3. Explain the goal, who benefits, and the expected behavior without including private school or personal data.
4. The development team plans approved work, tracks implementation and updates the issue as milestones are verified.

## Workflow

**Backlog → Todo → In Progress → Review → Done**

- **Backlog:** proposed work awaiting review
- **Todo:** approved and ready for planning or implementation
- **In Progress:** implementation or required checks underway
- **Review:** testing, review or acceptance remains
- **Done:** all applicable acceptance criteria have been met

Git integration does not automatically mean a feature is deployed or available to schools.

## Privacy and security

This repository is **public**. Do not post student, guardian or employee personal details; credentials; school-specific confidential documents; vulnerability exploits; or internal server information. Sensitive technical implementation, code and detailed validation remain in the private engineering repository.
